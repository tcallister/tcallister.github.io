Gravitational-wave data analysis is challenging: we can make only noisy measurements of an incomplete and biased slice of an underlying unknown astrophysical population.
As the number of gravitational-wave detections continues to balloon, new data analysis and inference methods prove key to extracting all available information from measured data.
